# Data sources and licensing

All external datasets used by this project originate from third-party sources, including public institutions and open data platforms.

## Data usage and transformation

- All source datasets are used as **source material only**.

- The project performs **substantial transformations**, including (but not limited to):

- Data cleaning and normalization

- Taxonomic resolution and consolidation

- Multilingual translation

- Semantic enrichment (icons, categories, colors, metadata)

- Structural reformatting for application use

As a result, the datasets produced by this project are **derived works** and are **not equivalent to the original source datasets**.

## Licensing and reuse

- Each source dataset remains subject to **its own legal and usage conditions** as defined by the original publisher.

- The **code** of this project is licensed under **GNU GPL-3.0**.

- Generated datasets are distributed under GNU GPL-3.0 **only to the extent permitted by the original data sources**.

- No claim of ownership is made over any third-party source data.

## Attribution and transparency

- All data sources used by this project are:

- Explicitly credited

- Linked to their original publication

- Described with their publisher, scope, and update date

This project is **not affiliated with nor endorsed by any data provider**, unless explicitly stated.
